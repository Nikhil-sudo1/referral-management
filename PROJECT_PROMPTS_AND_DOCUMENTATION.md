## 🏗️ Key Features Implemented

### 1. Payout Approval System
- **Two-level approval workflow**
- Student Admin → Account Team → Disbursement
- Status tracking:
  - `pending_student_admin`
  - `pending_account_team`
  - `approved_account_team`
  - `disbursed`

### 2. India Regional Analytics (Student Admin Dashboard)
- **Top Regions by Referrals** - Progress bar chart
- **Top Courses by Referrals** - Bar chart with Recharts
- **Top Referrers Leaderboard** - Ranked list with conversion rates

### 3. Leaderboard
- Sorted by total referrals (descending)
- Top 3 podium display
- Tier badges (Gold, Silver, Bronze)
- Conversion rate display

### 4. Referral Management
- Submit referrals with university/program selection
- Status tracking (submitted → assigned → contacted → admitted/rejected)
- Search and filter functionality
- Column visibility toggle

### 5. Authentication System
- JWT-based authentication
- Role-based access control (RBAC)
- Quick login buttons for testing
- Password reset functionality

### 6. Dashboard Features
- Animated counters
- Real-time statistics
- Charts and visualizations
- Dark mode support
- Notification system

## 🗄️ Database Schema

### Core Tables

```sql
-- Users
users (
    id UUID PRIMARY KEY,
    email VARCHAR(255) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    name VARCHAR(255) NOT NULL,
    phone VARCHAR(20),
    role_id INTEGER,
    user_type_id INTEGER,
    is_active BOOLEAN DEFAULT true,
    created_at TIMESTAMP,
    updated_at TIMESTAMP
)

-- Universities
universities (
    id UUID PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    code VARCHAR(20) UNIQUE NOT NULL,
    status VARCHAR(20),
    created_at TIMESTAMP
)

-- Programs
programs (
    id UUID PRIMARY KEY,
    university_id UUID REFERENCES universities(id),
    name VARCHAR(255) NOT NULL,
    code VARCHAR(50),
    reward_amount DECIMAL(12,2),
    status VARCHAR(20),
    created_at TIMESTAMP
)

-- Referrals
referrals (
    id UUID PRIMARY KEY,
    referral_code VARCHAR(50) UNIQUE NOT NULL,
    referrer_id UUID REFERENCES users(id),
    referee_name VARCHAR(255) NOT NULL,
    referee_email VARCHAR(255) NOT NULL,
    referee_phone VARCHAR(20),
    university_id UUID REFERENCES universities(id),
    program_id UUID REFERENCES programs(id),
    status VARCHAR(50),
    submission_date TIMESTAMP,
    created_at TIMESTAMP
)

-- Rewards
rewards (
    id UUID PRIMARY KEY,
    referral_id UUID REFERENCES referrals(id),
    user_id UUID REFERENCES users(id),
    user_type VARCHAR(50) NOT NULL,
    amount DECIMAL(12,2) NOT NULL,
    status VARCHAR(50),
    student_admin_approved_by UUID,
    student_admin_approved_at TIMESTAMP,
    account_team_approved_by UUID,
    account_team_approved_at TIMESTAMP,
    disbursed_at TIMESTAMP,
    created_at TIMESTAMP
)
```
