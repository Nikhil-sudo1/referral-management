# TeamLease EdTech - Referral Management Platform

A comprehensive referral management system for TeamLease EdTech to track and manage student referrals from 60+ university partners to 900+ corporate partners, monitoring placements and measuring employability outcomes.

## About This Platform

This platform is a specialized solution developed for TeamLease EdTech's referral ecosystem. It enables the company to:
- Track student referrals from partner universities
- Manage corporate placement referrals
- Monitor employability outcomes and conversion rates
- Measure ROI for universities and corporate partners
- Coordinate between educators, students, and employers

## About TeamLease EdTech

TeamLease EdTech is on a mission to build an ecosystem that makes Every Learner Employable. Through our experienced team, cutting-edge technology platform, and innovative pedagogy, we connect Education, Employability, and Continued Employability across India.

**Corporate Website:** [teamleaseedtech.com](https://www.teamleaseedtech.com/)

## 🌟 Features

### Core Functionality
- **📊 Interactive Dashboard** - Real-time statistics with animated counters and live data visualization
- **👥 Referral Management** - Comprehensive referral tracking from submission to admission
- **🎓 Referee Management** - Track referee (student) information and referral history
- **🏛️ University Portal** - Manage partner universities and programs
- **🏆 Leaderboard System** - Gamified ranking for referrers and counselors
- **💰 Rewards Tracking** - Monitor and manage reward disbursements

## 🚀 Quick Start

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Visit `http://localhost:5173` to see the application.

### Build

```bash
npm run build
```
